# clovercycle
Hi! This is the project clovercycle and is a website for the non-profit Clovercycle that focuses on informing people about how our health is linked to our environment. 

I made this project to help the nonprofit share its information beyond a local reach, and by doing this, we can connect to people all around the world!

I made this project using React (my first time), and there was quite a bit of a learning curve, especially since I was trying to use Tailwind at the same time. But I was able to do a little more with JavaScript, and I learned about using SVGs! I struggled with Tailwind, but Tailwind CSS has really nice documentation that was super helpful throughout the project! Through this project, I learned about hosting it on React and got more familiar with both JavaScript and Tailwind CSS!!
